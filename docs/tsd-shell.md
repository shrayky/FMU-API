# Оболочка задач ТСД

Срез 1 переноса сбора марок из мобильной 1С (`Ds-Check-Mark`) в `src/Presentation/TsdApp`. Главный экран — меню задач. Проверка марки — отдельный экран.

## Граница среза

В срезе есть меню, реестр задач, настройки кнопок и заглушки сбора марок. Проверка марки сохраняет текущее поведение и открывается кнопкой «Сервис».

Следующие срезы, в этот документ не входят:

- протокол обмена как интерфейс, первая реализация `ds-tsd`, поля подключения `host`, `port`, `https`, публикация, пользователь, пароль, таймаут;
- загрузка документа по штрихкоду и локальное хранение;
- подбор марок;
- журнал с данными и выгрузка документа;
- полная загрузка номенклатуры, True API, новая цена, Anydesk, пин-код настроек.

## Меню и проверка марки

`HomeScreen` — меню. Сканер на меню выключен: клавиатурный буфер марки, intent, буфер обмена и кнопка камеры живут на экране проверки.

`presentation/mark_check/mark_check_screen.dart` забирает текущий сценарий `HomeScreen`: фокус, intent, буфер, камера, карточка марки, непрерывное сканирование, запрос ИНН и `api/ts/checkMark`. Адрес Fmu-Api экран читает из сохранённых настроек. Пустой адрес показывает «Укажите адрес Fmu-Api в настройках». Свой поиск адреса и своя проверка обновления на этом экране отсутствуют.

Заголовок приложения и меню — «Fmu-Api». Заголовок экрана проверки — «Проверка марки». Кнопка настроек остаётся на меню. На экране проверки своей кнопки настроек нет.

На меню остаются:

- поиск Fmu-Api, если `apiBaseUrl` пустой;
- баннер «Поиск Fmu-Api в сети…» на время поиска;
- баннер «Укажите адрес Fmu-Api в настройках», если поиск ничего не нашёл;
- после успешного поиска адрес сохраняется, баннер скрывается;
- предложение обновить приложение и баннер ошибки проверки обновления, таймер проверки живёт на меню и продолжает идти, пока поверх открыта задача.

## Задача

`domain/task/tsd_task.dart` описывает задачу. Оболочка не знает экран проверки и экран сбора.

Поля:

| Поле | Смысл |
|---|---|
| `id` | стабильный код |
| `defaultTitle` | подпись, если в настройках пусто |
| `defaultSection` | `documents` или `service` |
| `hasJournal` | у задачи есть журнал |
| `open` | экран задачи, аргумент — текущие `AppSettings` |
| `openJournal` | экран журнала; вызывается только при `hasJournal` |

`application/shell/task_registry.dart` содержит две задачи:

| id | Подпись | Раздел | Журнал | Экран |
|---|---|---|---|---|
| `markCollection` | Сбор марок | `documents` | да | заглушка |
| `markCheck` | Проверка марки | `service` | нет | `MarkCheckScreen` |

Новая задача добавляется в реестр. `HomeScreen` из-за неё не меняется.

Заглушка сбора: заголовок «Сбор марок», текст «Сбор марок будет в следующей подзадаче». Журнал: заголовок «Журнал», текст «Журнал сбора марок».

## Кнопки

`domain/task/task_button.dart`:

| Поле | Смысл |
|---|---|
| `taskId` | код из реестра |
| `section` | `documents` или `service` |
| `title` | подпись на кнопке |
| `order` | порядок внутри раздела, меньше выше |
| `hotkey` | один символ или пустая строка |
| `showJournal` | показать кнопку журнала |
| `enabled` | кнопка видна |

`application/shell/task_buttons.dart` собирает видимый список:

- нет сохранённых кнопок — две кнопки по умолчанию: «Сбор марок» (`order` 1, журнал включён) и «Проверка марки» (`order` 1, журнал выключен), обе включены;
- сохранённая кнопка с неизвестным `taskId` отбрасывается;
- для известной задачи без сохранённой строки берётся значение по умолчанию;
- выключенные кнопки скрыты;
- внутри раздела сортировка по `order`, затем по подписи;
- пустая подпись заменяется на `defaultTitle`;
- горячая клавиша длиннее одного символа не срабатывает;
- журнал рисуется, когда `hasJournal` и `showJournal`; у проверки марки переключатель журнала в редакторе скрыт.

Вкладки «Документы» и «Сервис» видны только при наличии хотя бы одной включённой кнопки в разделе. Если включённых кнопок нет, тело меню — «Все задачи выключены».

Строка кнопки: широкая кнопка с подписью и горячей клавишей в скобках, справа кнопка журнала. Пустая горячая клавиша в подпись не добавляется.

Клавиши меню, пока оно в фокусе:

- влево и вправо переключают видимые вкладки; при одной вкладке ничего не делают;
- символ горячей клавиши открывает задачу, даже если её вкладка сейчас не выбрана; сравнение без учёта регистра; при двух совпадениях открывается первая кнопка в порядке раздела «Документы», затем «Сервис», внутри раздела по `order` и подписи.

Поверх меню фокус у открытой задачи, горячие клавиши меню не обрабатываются.

## Настройки

Кнопки входят в `AppSettings` и пишутся в `SharedPreferences` ключом `taskButtons` (JSON-массив). Битый JSON и пустое значение дают набор по умолчанию. Остальные ключи настроек не меняются.

В `settings_screen.dart` пункт «Задачи» открывает список кнопок. Строка открывает редактор: раздел, подпись, порядок, горячая клавиша, журнал, включена. Задачу удалить нельзя, её можно выключить. Добавить код вне реестра нельзя.

Редактор возвращает строку в список. Запись на диск происходит по «Сохранить» на экране настроек. Уход из настроек без сохранения оставляет прежние кнопки. Пустой или нечисловой порядок сохраняется как 1.

Горячая клавиша — один символ или пустая строка. Повтор символа среди кнопок редактор не закрывает и показывает «Такая горячая клавиша уже задана». Сравнение символа без учёта регистра.

## Ошибки

Поиск Fmu-Api и проверка обновления на меню ведут себя как сейчас на главном экране: сеть недоступна — баннер адреса или баннер сбоя обновления, меню остаётся рабочим. Экран проверки при ошибке запроса показывает ту же карточку ошибки, что и сейчас.

## Проверка

Юнит-тесты `task_buttons`: значения по умолчанию, отбрасывание неизвестного кода, подмешивание отсутствующей задачи, скрытие выключенных, сортировка, пустая подпись, журнал только при обоих флагах, горячая клавиша длиннее одного символа.

Виджет-тесты меню: две вкладки и обе кнопки по умолчанию, выключенная проверка марки скрыта, горячая клавиша открывает проверку марки, пустой набор показывает «Все задачи выключены», на меню нет `ContinuousScanTable` и кнопки камеры.

Существующие тесты `widget_test.dart`, которые открывают проверку марки, непрерывный режим, камеру и буфер обмена, переносятся на `MarkCheckScreen`. Поиск адреса и баннер обновления проверяются на `HomeScreen`.

Команда: `flutter test` в `src/Presentation/TsdApp`.
