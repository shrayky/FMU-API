# AGENTS.md

Правила для работы в этом репозитории. Дополняют `.cursor/rules/`.

## Именование асинхронных методов

Суффикс `Async` не используем. Метод, возвращающий `Task` или `Task<T>`, называется по действию без суффикса.

```csharp
// ❌ BAD
Task<Result> ProbeAsync(FrontolConnectionSettings connection, CancellationToken cancellationToken);

// ✅ GOOD
Task<Result> Probe(FrontolConnectionSettings connection, CancellationToken cancellationToken);
```

Асинхронность метода видна по типу возвращаемого значения, дублировать её в имени не нужно. Так написано большинство методов в репозитории.

Методы с суффиксом `Async`, которые уже есть в проекте, не переименовываем: это отдельная задача, а не побочная правка по ходу другой работы. Методы платформы и библиотек (`SendAsync`, `OpenAsync`, `ReadAsync`) сохраняют свои имена.

## Сборка

```bash
dotnet build FMU-API.sln
```

Юнит-тестов в репозитории пока нет, проверка — сборка и ручной сценарий.

Если сборка падает с `Access to the path '...\obj\...' is denied` или `MSB3491`, значит каталоги `obj` и `bin` закрыты для записи текущими правами или песочницей. Это не ошибка кода: нужны права на запись в эти каталоги.
